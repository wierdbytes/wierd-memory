# Changelog

## [0.1.0] - 2026-11-10

### Added

- First npm release: `pi install npm:@wierdbytes/pi-memory`.
- `<memory>` injection of the approved index and approved skills.
- Tools `memory_search`, `memory_read`, `memory_inbox`; commands `/memory`, `/dream`, `/remember`; flag `--no-memory`.
- Server auto-start via the launchd agent (`wmem service install`) or `wmem` on `PATH`.
